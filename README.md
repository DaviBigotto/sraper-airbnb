# 📸 Airbnb Photo Downloader Pro

Aplicação completa para extração e download em lote de fotos de anúncios do Airbnb em máxima qualidade (1920p / Ultra HD) com um único clique.

## 🚀 Como Executar

### 1. Iniciar o Servidor
No terminal, dentro da pasta do projeto (`C:\Users\davib\.gemini\antigravity-ide\scratch\airbnb-photo-downloader`), execute:

```bash
npm start
```

### 2. Abrir a Aplicação no Navegador
Abra o seu navegador e acesse:
👉 **[http://localhost:3000](http://localhost:3000)**

---

## 🌟 Funcionalidades

- **Extração Automática HD**: Basta colar o link de qualquer anúncio do Airbnb (`.com` ou `.com.br`) e o servidor varre e extrai a galeria completa.
- **Resolução Máxima**: Converte automaticamente as miniaturas para qualidade 1920p (Ultra HD).
- **Download em 1 Clique (ZIP)**: Compacta todas as imagens (ou apenas as selecionadas) em um único arquivo `.zip`.
- **Download Individual**: Baixe qualquer foto específica diretamente da galeria.
- **Lightbox / Zoom Visual**: Clique em qualquer foto para abrir em tela cheia com navegação por setas do teclado.
- **Design Moderno**: Interface em modo escuro (Dark Glassmorphism) responsiva e rápida.
